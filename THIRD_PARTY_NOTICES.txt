Optional Native Codecs
----------------------

Optional native codec features other than native-webp are explicit build choices
and are not enabled in the default binary. If a release enables native-avif or
native-ai, the release bundle must include the license text and attribution for
the corresponding native library and all packaged runtime binaries.

native-avif uses the Rust libavif crate with libavif and dav1d.
License: BSD-2-Clause for libavif-rs; libavif and dav1d use BSD-style terms.
Source: https://crates.io/crates/libavif, https://github.com/AOMediaCodec/libavif,
and https://code.videolan.org/videolan/dav1d

native-ai uses pdfium-render to call an app-local PDFium dynamic library.
License: MIT OR Apache-2.0 for pdfium-render; PDFium uses BSD-style terms plus
Apache-2.0-covered components.
Source: https://crates.io/crates/pdfium-render,
https://pdfium.googlesource.com/pdfium/, and
https://github.com/bblanchon/pdfium-binaries
Note: The repository does not commit PDFium binaries. Development builds may
use scripts/fetch_pdfium.py to fetch a V8/XFA-free PDFium package. Release
packaging must record the package URL and checksum and ship the PDFium license
text with the bundle.

Benchmark-only native candidates such as TurboJPEG are not production decoder
settings in the default application.
